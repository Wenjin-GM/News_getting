# 一览 · Android 独立版 3.0.0

安装 APK、连接网络即可使用。界面、新闻采集和解析、AI 工具目录、收藏及缓存全部在手机内运行，不需要 ChatGPT、任何聚合云站点、API 密钥、电脑或自建后端。网络请求只直接发送到内置新闻来源；浏览原文时由用户打开外部浏览器。

## 安装与分享

成品位于工作空间 `releases/android/yilan-standalone-3.0.0.apk`，同目录提供 SHA-256、签名指纹和版本信息。适用于 Android 8.0 及以上，无处理器架构限制，没有捆绑浏览器内核。

把原始 APK 发送到手机安装，或直接转发给其他人。应用「设置 → 分享本应用安装包」也能分享手机上已经安装的 APK，对方不需要账号。Android 会要求确认外部来源安装；不要关闭系统安全扫描或绕过风险拦截。完成后可关闭发送工具的外部来源安装开关。

## 使用

- 打开应用即检查更新；「一键更新」并发获取所有已启用来源。36 个来源内置，默认启用 29 个；实验来源可在设置开启。
- 新闻、热搜、科技、财经、社区分类，搜索、收藏、已读筛选、紧凑及大字阅读。点击新闻在应用内阅读来源提供的标题与摘要；完整原文是可选的外部浏览器入口，不是应用获取或展示新闻的前提。
- AI 专栏包含直连动态、16 家平台和 31 项编程工具 / Harness / SDK。支持平台筛选、最多 3 项对比和官方资料入口。目录是内置资料快照，随 APK 版本维护，核对日期在应用中显示。
- 成功获取后保存快照；来源失败不删除旧内容，明确显示失败和采集时间。断网可读已保存的标题、摘要、收藏和内置目录；最新新闻与外部原文需要网络。
- 每个来源有超时、登记主机限制、同平台备用渠道、缓存间隔、失败暂停及 5 MB 响应限制。手机自身网络无法访问的来源会失败；应用不会绕过登录、验证码或地域限制。
- 不提供关闭应用后的常驻后台服务和消息推送。收藏只在本应用内，卸载或清除数据会删除。旧 2.1 网页外壳的收藏不自动迁移。

## 安全边界

安装包仅声明 `android.permission.INTERNET`。不申请存储、相机、麦克风、通讯录、定位或安装其他应用的权限，不读取本机目录。无 WebView、网页脚本、JavaScript 原生桥接、广告 SDK、统计 SDK、模型调用或动态代码下载。

缓存写入 Android 给本应用分配的私有沙箱，并采用原子写入。安装包分享使用未导出的只读 ContentProvider，只向用户选择的接收应用临时授权 `/release.apk`，实际文件固定为本应用安装文件；不能用 URI 指定任意本地路径或写入文件。

只抓取随 APK 登记的公网 HTTPS 来源，不接受用户提供的抓取地址。跳转限制在该来源已知主机，使用系统证书与主机名验证，不绕过 TLS 错误。解析结果以原生文本呈现，不执行来源网页中的代码。原文和工具资料在外部浏览器中处理，外部网站后续行为不属于本应用沙箱。

发布签名与校验能验证文件一致性，不是杀毒认证，不能保证不存在所有漏洞。请保持 Android 系统和外部浏览器更新，保留设备安全防护。

## 源码与构建

- `src/cn/yilan/news/NewsEngine.java`：手机直接联网、RSS / Atom / JSON / HTML 适配器及数据规范化。
- `MainActivity.java`：全部原生界面、本地缓存、阅读与收藏。
- `ApkProvider.java`：只分享本应用 APK 的受限只读接口。
- `assets/sources.json`、`assets/ai-catalog.json`：由构建脚本从项目资料复制进 APK。

运行 `scripts/android/prepare.py` 准备官方校验过的便携 JDK / Android 构建工具，再运行 `scripts/android/build.py` 编译和签名。构建脚本检查仅联网权限、内置资料与禁止的网页运行依赖。发布密钥在忽略目录 `.local/signing/android`，请单独妥善保管；不要把密钥或密码分享。3.0 使用与 2.1 相同的发布证书，可覆盖升级。

运行 `python scripts/android/test.py` 执行 JVM 单元测试，添加 `--live` 开启直连检查。`android/tests/NativeEngineTest.java` 是测试入口。可选 `scripts/android/prepare-tests.py --emulator` 将模拟器与测试依赖放入 `.cache/android`；测试依赖不打进 APK。工作空间外不安装 SDK、Java、驱动或服务。

旧版 Sites / PWA 已从当前源码移除。正式成品见 `releases/android`；本地构建输出为 `dist/android`，不会自动覆盖正式发布文件。
