# AI 专栏 · 1.1.0

在左侧导航（手机底部导航）点击 **AI 专栏**。此升级保留原有新闻、来源设置、收藏与历史数据，不需要模型 API Key。

## 四个入口

- **平台动态**：官方新闻、产品更新日志、仓库版本发布，以及明确标注的媒体补充资讯。按发布时间排列，支持厂商筛选、仅官方、仅版本和搜索。
- **编程产品**：桌面、IDE / 插件、CLI、Web 等直接可使用的产品。
- **Harness / SDK**：执行智能体任务的 harness、调用既有 harness 的 SDK、通用 Agent 框架，分别标注类型和定位。
- **平台地图**：16 家平台的官方入口、已收录工具、自动采集渠道覆盖情况。

当前目录涵盖 OpenAI、Anthropic、Google、GitHub / Microsoft、阿里 / Qwen、Kimi、DeepSeek、MiniMax、Mistral、智谱 / Z.ai、字节 / TRAE、腾讯 / CodeBuddy、百度、xAI / Grok、AWS / Kiro、Hugging Face，共 31 项产品或组件。

## 动态与目录的区别

动态来自 16 条官方渠道和 2 条媒体 RSS 筛选渠道。官方渠道包括 OpenAI 新闻、Anthropic 新闻、Google AI、Hugging Face 博客、GitHub Copilot 更新、DeepSeek / ZCode 更新日志，以及 Codex、Claude Code、Qwen Code、Kimi Code、MiniMax Code、Mistral Vibe 等官方仓库版本发布。

媒体补充来自 IT之家和爱范儿，按 AI 相关标题关键词筛选，存在漏报和误报可能。部分厂商尚无接入的可靠官方自动渠道，平台地图会如实标注，通过媒体补充与官方入口跟踪，不冒充已经自动覆盖。

点击 **更新 AI 动态** 只更新 AI 来源；普通「今日一览」更新常规新闻。来源管理中的刷新仍可覆盖全部。刷新任务同时只运行一轮，期间重复点击复用同一轮结果。

版本发布含预发布、测试版、nightly。工具卡上的版本条目是「最近采集的发布记录」，不是对最新版、正式版或稳定性的承诺。低频软件可能数周没有新版本，因此不沿用日报新闻的七天停更判定。

只有日期的公告保持日期精度，不人为补出具体发布时间。新闻来自官方也不代表已经事实核查。

## 如何使用目录

支持按平台、工具形态、开源情况筛选及关键词搜索。每个条目都有官方依据、用途定位、许可说明和核对日期；详情中可以打开官网和官方仓库。

点击卡片上的 **对比 +** 可加入最多 3 个工具，查看类型、出品方、角色、许可与提示的对比表。

点击 **导出目录** 可保存 Markdown、HTML、JSON；导出首先保存在 `data/exports/`，也可下载副本到手机。动态快照可以单独导出。

目录核对日期为 **2026-10-28**。产品归属、开源结论和用途由人工依据官方资料维护，不随每次新闻刷新自动推断或改写；动态和发布记录则随采集更新。未确认核心开源不等于确认闭源，公开仓库也不一定含产品核心源码。

## 几个容易混淆的地方

- OpenAI Codex 的产品入口、CLI / app-server harness、SDK 分层列出。
- Claude Code 的公开发布仓库不作为核心运行时代码开源的证据。
- Google Antigravity 有 App、CLI、IDE、SDK；Gemini CLI 保留发布跟踪并注明官方个人用户迁移通知。
- DeepSeek 已有官方开源 Harness 预览版，不能用「只有模型 API」的旧结论代替。
- TRAE IDE 与开源 Trae Agent 是不同项目。
- 通用 Agent 框架如 ADK、smolagents 不直接当成现成编程客户端。
- 使用某家模型的第三方工具不归到该模型厂商名下。

专栏仅展示与导出信息，不会安装、登录或运行目录里的工具，不会更改这些产品的配置。所有项目文件和数据仍保存在当前目录内。
