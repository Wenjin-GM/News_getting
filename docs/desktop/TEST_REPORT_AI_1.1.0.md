## 已交付

## 资源与限制

可执行文件约 13.1 MiB，ZIP 约 5.6 MiB；一个实际静置样本的进程工作集约 35.8 MiB，不包含浏览器，也不是长期峰值承诺。

31 个产品官方入口自动探测中，28 个直接响应成功；灵码与两个 CodeBuddy 入口遇到连接重置 / 超时，无 404。它们有先前官方页面核实依据，目录中保留官方链接，不以一次网络失败认定产品不存在。

五家平台目前没有接入官方自动动态源，通过媒体补充和官方入口跟踪，界面明确标注覆盖边界。媒体筛选依赖关键词，可能漏报或误报。版本 feed 可能包括 alpha / beta / nightly，不当作稳定版保证。目录是人工核对快照，不会根据新闻自动推断产品归属；后续产品变化需要维护目录。

未安装或执行目录里的任何 AI 工具；没有调用模型 API 或产生模型调用费用。所有主动修改的文件、缓存、导出、备份和产物均在当前工作空间。已启动新版后台进程，沿用局域网端口 8765；未修改防火墙、系统代理、注册表、开机启动或休眠设置。
