# NewsDesk 1.0.0 验收记录

> 历史快照：以下记录对应 1.0.0 当时的测试、目录和渠道情况，保留原始结论，不代表现行版本状态。当前入口为 [HANDOFF](../../HANDOFF.md)，路径迁移见 [目录说明](../STRUCTURE.md)。

验证日期：2026-10-28，Asia/Shanghai。测试在当前 Windows 电脑与当前网络中进行，持续时间约半小时，不能替代七天稳定性观察。

## 结果

- 便携发布版在全新数据目录首次启动成功，18 个来源定义、11 个默认启用。
- 全新采集：11 个默认来源全部取得有效内容，共 320 条，约 5 秒完成。
- 旧版首轮与后续探测发现微博、知乎、B站、百度热搜、BBC 受连接或访问限制，已默认关闭。
- 人民网 RSS 虽返回 HTTP 200，但最新条目停留在 2025-06-05，已默认关闭。新增内置 RSS 过旧 / 异常未来时间校验。
- 新版实际点击「一键获取」可完成整个流程；60 秒内请求过的来源沿用已有快照，并独立计数，不虚增成功次数。
- 新版可执行文件约 13.0 MiB，便携 ZIP 约 5.6 MiB。
- 一次运行时工作集约 30～31 MiB（不包含浏览器，非长期峰值保证）。

## 自动测试

`scripts/test.ps1`：7 个后端测试全部通过，JavaScript 语法检查通过。

1. RSS / Atom 解析、摘要清理、重复链接与非 HTTP 链接过滤。
2. JSON 大整数 ID 保留，验证码 / 非 JSON 页面拒绝。
3. API 未授权拒绝，来源开关与访问密钥重启保留，页面资源内嵌。
4. 采集失败保留快照，缓存和失败不算新请求成功，最小间隔生效。
5. 成功快照、历史、收藏持久化，以及安全 HTML 导出和目录边界。
6. 并发刷新合并为同一任务。
7. 已长期停更的官方 RSS 不算当前新闻，自定义低频订阅允许长期未更新。

`scripts/smoke.mjs` 对实际发布二进制执行：新目录启动、401 访问控制、11 源真实请求、添加自定义财经 RSS 并采集、移除临时 RSS、导出 JSON、API 安全停止，全部通过。测试数据单独存于项目 `.cache/`，未混入便携包。

## 界面验证

- 真实浏览器打开聚合页并展示真实新闻。
- 收藏和取消收藏、收藏列表、搜索关键词验证通过。
- 手机入口、网络地址选择与本地二维码生成可用；网络地址优先 WLAN，避免默认选择虚拟机网卡。
- HTML 导出成功，320 条静态快照保存在 `data/exports/`。
- 内容归档、日期入口与采集记录可读取。
- 390 × 844 手机视口检查，无横向溢出，底部导航与卡片可读。
- 最终页面浏览器 error / warn 日志为空。
- 截图：`preview-desktop.jpg`、`preview-mobile.jpg`。

## 尚未验证或未包含

- 没有真实安卓 / iPhone 硬件，也未代替用户修改 Windows 防火墙，因此手机跨设备连通性仍受实际 Wi-Fi、防火墙与设备隔离影响。
- 没有长期成功率或平台可用性 SLA；不同网络结果可能不同。
- 当前提供手机适配网页，没有原生安装包、完整 PWA 离线安装、外网私有组网或后台推送。
- 新闻接口内部缓存无统一更新时间时无法独立判断，采集成功不保证所有条目为最新发生事件。
