# 安全边界

Android 独立版在手机上直接采集公开新闻，使用原生界面展示标题和摘要。只申请 `INTERNET` 权限，没有 WebView、JavaScript 桥接、广告或统计 SDK，不读取手机目录或其他应用数据。缓存、收藏和偏好写入应用私有沙箱。

安装包分享接口未导出，只允许对固定 `/release.apk` 地址进行只读操作；仅向用户在系统分享面板选中的接收方授予临时读取本应用 APK 的权限。无上传私人收藏、目录浏览或任意文件读写接口。模拟器验收确认未授权访问被 Android 拒绝。

采集仅访问内置来源登记的公网 HTTPS 主机，保留系统 TLS / 主机名验证。限制重定向、超时、正文大小与 JSON 嵌套深度，失败保留快照。新闻文本不会作为 HTML 或脚本执行。完整原文和工具官方资料由用户选择在外部浏览器打开，后续网站行为超出应用沙箱。

Windows 版是单独的本地服务，默认仅监听回环地址，API 由访问密钥保护；开启局域网访问需主动运行对应启动器。其数据库和密钥保存在本地 `.local/runtime/desktop/data/`，不会提交 Git。

发布密钥只保存在 `.local/signing/android/`，仓库仅提供 APK、公开证书指纹与 SHA-256。自行构建时新生成的签名密钥与正式发布包不同，不能直接覆盖安装正式版本。不要分享签名目录或个人数据目录。

签名与哈希用于验证文件一致性，不是第三方杀毒认证。手机网络和新闻源限制可能导致部分渠道失败；这不应通过关闭证书验证、系统扫描或安全防护来解决。请保持操作系统与外部浏览器更新。
