> 文档标注：本文件是 3.0.0 交付阶段的验证快照，不是每次打开工作空间都会重跑的结果，也不是全机型认证。当前版本/状态先读 [HANDOFF](../../HANDOFF.md)；文档身份见 [架构记忆](../../memory/architecture.md)。

最终交付：releases/android/yilan-standalone-3.0.0.apk，62,219 字节，Android 8.0+。

- 原生 APK 的 UI、来源配置、解析器、AI 目录、缓存及收藏全部内置；没有 WebView 或 chatgpt.site 依赖。
- JVM 对 RSS/Atom/JSON、文本清理、危险 URL、停更检测、稳定 ID、离线快照序列化的测试通过。
- 原生 Java HTTPS 引擎 29/29 默认来源成功，返回 589 个源条目。详细报告见 direct-network-test.json。
- Android 11 模拟器成功安装正式签名 APK，实际首次采集界面显示 29 来源更新成功、失败 0；新闻展示、收藏、AI 动态和内置工具目录可操作。
- 对同一签名的 3.0 APK 覆盖安装后，模拟器开启飞行模式，确认 Active default network: none。冷启动仍显示 308 条综合新闻及 1 条收藏；本轮更新 0、沿用 26 个来源快照、3 个来源失败，失败没有清空历史内容。
- SDK 签名验证与实际安装权限检查通过，仅 INTERNET；调试与系统备份关闭。分享 APK 的 ContentProvider 未导出，未授权 shell 读取确实被 Android 拒绝。
- APK 中含 36 个来源配置和 31 项 AI 工具资料；发布 APK 和源码分发 ZIP 不含私钥或工具链。
- 这是模拟器与引擎层测试，不是所有实体机型的兼容性认证或第三方杀毒认证。
