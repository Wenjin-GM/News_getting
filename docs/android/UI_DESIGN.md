## 视觉依据

- [AIHOT](https://aihot.news/)：参考清晰的标题/来源层级、轻量筛选、按日期组织与边框卡片。3.7当时仅作视觉参考；3.8.6后按用户要求接入其公开RSS，未采用其评分。
- [晚霞预测·武汉](https://glowsunset.cn/#!wuhan)：参考墨蓝底、柔和暖色点缀、圆角面板及聚焦内容的详情层。不使用其图片、字体文件或页面脚本。

沿用现有阅读路径，保留搜索与更新同排；删除各分页的大标题。背景图片置于整个页面内容下，不占据列表高度；不增加口号、装饰性数据或跨来源热度分数。

## 内置图片与渲染

使用内置 image_gen 工具新生成三张原创静态背景，没有使用 API Key：

| 页面 | 项目资源 |
| --- | --- |
| 新闻（各阅读模式共用） | [城市信息流](../../android/res/drawable-nodpi/scene_news.png) |
| AI 专栏（各模式共用） | [神经网络光场](../../android/res/drawable-nodpi/scene_ai.png) |
| 收藏 | [星轨与晶体档案](../../android/res/drawable-nodpi/scene_saved.png) |
| 设置 | 无图片，保留纯色底 |

完整生成提示词与资源路径留在 [android-background-prompts.json](../../assets/android-background-prompts.json)。成图工具自动在其默认生成目录保留了原始缓存；以上三张选定图片已复制入工作区，APK 只引用项目内资源，不依赖工具目录或在线图片。

ReaderBackdrop 以 center-crop 铺图，再叠加随日夜变化的渐变遮罩与边缘细刻度。只持有当前页位图，解码目标最多约 200 万像素，不在每次刷新时重复解码；加载失败保留纯色/渐变兜底。背景固定，无视频、常驻动画或逐卡片实时模糊。

GlassPanelDrawable 以半透明渐变填充、细亮边和两层低透明描边表现泛光。新闻、AI、收藏卡片及操作按钮浮在图片上；设置保持原有实色控件。详情弹窗保留高可读性的日夜表面。

## 配色与排版

颜色实现由 `ReaderTheme.java` 管理；原生主题/对话框属性在 `res/values/styles.xml` 中对应。不要另写页面专属的黑白硬编码。

| 用途 | 日间 | 夜间 |
| --- | --- | --- |
| 页面底色 | `#F5F5F0` 纸白 | `#0B111B` 墨蓝 |
| 设置/弹窗基础表面 | `#FFFFFF` | `#131E2B` |
| 正文 | `#1E2E32` | `#EDF0F4` |
| 来源/时间 | `#5B6C70` | `#9FAEBB` |
| 强调色 | `#16646D` 松石蓝 | `#87D4CC` 浅青 |
| 暖色点缀 | `#9B5635` | `#EDBD9D` |

- 系统 sans-serif / sans-serif-medium，无联网字体或新增运行依赖。正文通常 14–17sp，列表标题 17sp，来源/时间至少 12sp；分页大标题已移除，大字阅读与系统字体缩放继续生效。
- 卡片圆角 20dp、弹窗 24dp、按钮约 12–16dp。列表卡片整块可点，保留已读淡化；元信息继续位于标题下，不把摘要重新塞回新闻预览。
- 底栏采用原生线性图标，文字显式 wrap-content 并居中，与图标共用纵向中线；关闭横栏基线对齐。原先纵向 LinearLayout 默认子项 MATCH_PARENT 导致文字靠左，修正尚待新一轮真机复验。
- 模式、分类、国内/国外、厂商、工具类型筛选统一为靠左纯文字，无胶囊或边框；当前模式通过加粗/文字下划线区分，点击范围与原单选/多选语义保留。日期/榜单折叠标题是分组操作，不作为筛选器改写。
- 新闻详情将收藏、分享、原文合在同排。工具介绍适度截断，全文仍可在详情查看；模型优劣势/分析/出处继续位于详情，对比表有独立单元格层次。
- 弹窗、输入框、勾选项、来源开关、进度条和系统栏一起适配日夜颜色。控件保留点击反馈，状态切换不改变采集/归并规则。

## 主题行为与兼容

设置 → 外观 → 日间 / 夜间。选择立即作用于当前原生界面，保存后下次打开沿用；本轮没有新增跟随系统选项。

沿用 `native-news-v3.json` / schema 3，增加 `themeMode` 字符串。旧文件缺字段或值未知时默认日间。切换时重建视图而不重建采集引擎，保留当前页、查询、刷新进度、收藏、已读和来源开关。工具/模型资料和它们的日期不因主题改变而重写。
